I initially started this project years ago with the plan to write guides and post them on rentry.org, mainly for personal reference and to send friends. The short story is that life and a (at the time) newly found faith pulled me away from pokemon/gaming entirely after I wrote a couple of guides, and I never finished it. This is very much a work in progress so I wouldn't currently recommend anyone use or reference this site. I'm also avoiding giving any timeline or deadline intentionally, it will be done when it's done. And yes the web design does intentionally look like it's from the 90s/00s.

Welcome!

This website exists to provide comprehensive, low fluff guides for all pokemon games. As this is a massive project and I'm only one man, many guides are currently unfinished or not even started.

Why use these guides over Serebii/Bulbapedia/etc.?

While sites like Serebii and Bulbapedia are great resources for game data and how mechanics work (I actually use and link to both very often), they don't always make for great user guides. The goal of this page isn't just to provide information of how shiny hunting works, but also to make translating that into real in-game hunts easier for the average person.
